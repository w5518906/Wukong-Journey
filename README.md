# 🐒 悟空西游记

> 齐天大圣·海面划船大冒险 — 3D 网页小游戏

孙悟空在海面划船冒险，遇到小妖怪、障碍物和金币。捡金币加分，被妖怪撞击扣血。支持加速冲撞、大招灭海盗船、多视角切换等丰富玩法。

## 🎯 玩法说明

### 基本操作

| 按键 | 功能 |
|------|------|
| **A** / ← | 左移 |
| **D** / → | 右移 |
| **Shift** | 加速冲撞（气垫船模式，撞翻小妖） |
| **Q** | 大招（消灭海盗船 BOSS） |
| **C** | 切换视角（5 种循环） |
| **P** / **Esc** | 暂停游戏 |
| 🖱️ 拖曳 | 旋转视角 |
| 🖱️ 滚轮 | 缩放距离 |

### 游戏规则

- ❤️ **血条**：共 100 点，被妖怪/障碍撞击 -10 点（BOSS -15 点），归零则游戏结束
- 🪙 **金币**：捡到 +10 分，连吃 10 个额外回血 5 点
- 🍑 **蟠桃**：5% 概率出现，捡到 +20 血
- 🛡️ **无敌时间**：被撞后 1.5 秒无敌闪烁
- ⚡ **加速**：持续 5 秒，冷却 20 秒，加速时可撞翻所有小妖（+5 分/只），但礁石不可撞翻
- 🔥 **大招**：BOSS 出现时可用，消灭 BOSS 获得 +50 分 +20 血 +3 金币掉落，冷却 10 秒
- 🏴‍☠️ **海盗船 BOSS**：每 30 秒可能出现，持续发射炮弹远程攻击，必须用大招消灭

## 🛠️ 技术栈

- **Three.js** — WebGL 3D 渲染引擎（CDN 加载）
- **Web Audio API** — 程序化合成音效，无需音频文件
- **原生 JavaScript** — 无框架依赖
- **单 HTML 文件** — 无需构建，浏览器直接打开

## 🚀 本地运行

### 方式一：直接打开

将 `index.html` 下载到本地，用现代浏览器（Chrome / Edge / Firefox）打开即可。

### 方式二：本地服务器

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`。

> ⚠️ 首次加载需要联网获取 Three.js CDN，之后可离线运行。

## 📦 部署到 GitHub Pages

1. Fork 或推送此仓库到 GitHub
2. 进入仓库 **Settings → Pages**
3. Source 选择 **Deploy from a branch**
4. Branch 选择 **main** / **root**
5. 保存后等待 1-2 分钟即可通过 `https://your-username.github.io/悟空西游记/` 访问
